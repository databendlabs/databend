=== script_udf_inside_sql_lambda_body_is_rejected ===
description: A script UDF cannot be lifted out of a SQL lambda body, so it must be rejected with a clear error instead of leaking an internal column id.
sql: SELECT array_transform([a], x -> add_one(x)) FROM t
status: error
code: 1065
message: UDF "add_one" is not supported in the lambda body of array_transform, because script and server UDFs are evaluated by a separate plan node

=== lambda_udf_wrapping_script_udf_inside_sql_lambda_body_is_rejected ===

=== udaf_script_inside_sql_lambda_body_is_rejected ===
