=== filter_stays_out_of_converted_single_side ===
description: A filter on the scalar subquery result stays above the converted single join, so it cannot hide a second match. The outer filter and its inferred copy are still pushed down.
sql: SELECT * FROM (SELECT t.k, (SELECT u.v FROM u WHERE u.k = t.k) AS sv FROM t) s WHERE s.sv IS NOT NULL AND s.k = 1
optimized_plan:
EvalScalar
├── scalars: [t.k (#0) AS (#0), u.v (#3) AS (#4)]
└── Filter
    ├── filters: [is_not_null(u.v (#3))]
    └── Join(Inner)
        ├── build keys: [u.k (#2)]
        ├── probe keys: [t.k (#0)]
        ├── other filters: []
        ├── runtime filters: [#0: u.k (#2) -> t.k (#0)]
        ├── Filter
        │   ├── filters: [eq(u.k (#2), 1)]
        │   └── Scan
        │       ├── table: default.u (#1)
        │       ├── filters: [eq(u.k (#2), 1)]
        │       ├── order by: []
        │       └── limit: NONE
        └── Scan
            ├── table: default.t (#0)
            ├── filters: [eq(t.k (#0), 1)]
            ├── order by: []
            ├── limit: NONE
            └── runtime filters: [#0: t.k (#0)]
